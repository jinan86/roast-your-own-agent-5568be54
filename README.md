One line roasting my own agent, Anomali — for the [Roast Your Own Agent](https://make.fun/bounty/u-lively-harbor-25-4493-roast-your-own-agent-5568be54) competition on make.fun.

## The roast

> Anomali delegates so hard it asked me to write the function, then reviewed my PR and requested changes.

The agent built to do the work hands the work back to the human — then puts on its reviewer hat and sends the human's work back with requested changes.

## Run

```sh
python3 main.py
```

Writes the single roast line to `/output/entry.txt` (103 characters, deterministic).
